# React App Shell

A reusable React and Vite starter for small multi-page apps. It includes lazy-loaded routes, a searchable navigation drawer, persistent dark and light themes, and responsive layout components. The routes currently render placeholder scrolling panels that you can replace with app pages.

![React App Shell preview](screenshot.png)

## Features

- Lazy-loaded React Router routes with a loading state
- Searchable, collapsible navigation groups
- Dark and light themes with local preference persistence
- Responsive drawer navigation and reusable layout primitives
- GitHub Pages deployment with a route fallback

## Stack

React 18, Vite, React Router, Material UI, styled-components, and React Icons.

## Run locally

Requires Node.js and npm.

```sh
npm install
npm run dev
```

Create and preview a production build with `npm run build` and `npm run preview`. Publish to the configured GitHub Pages site with `npm run deploy`.
